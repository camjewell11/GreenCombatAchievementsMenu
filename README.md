# Green Combat Achievements

A RuneLite plugin that highlights a boss's name green in the Combat Achievements
list once every combat achievement task for that boss has been completed.

## Status

Scaffolded from the [RuneLite example-plugin](https://github.com/runelite/example-plugin)
template. The widget lookups needed to read the Combat Achievements interface and
per-boss completion state are not wired up yet.

See [AGENTS.md](AGENTS.md) for RuneLite plugin development guidelines and the
rules governing what plugin-hub submissions are allowed to do.
